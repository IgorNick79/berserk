# Bot Whip follow-up

2026-11-16. Смотритель стойла (s1_7), «Щелчок хлыста».

Причина: нативные turn_start:whip и pending_whip не входили в поддержанные проекции LegalActions/CombatDecisionPlanner. Из-за unsupported_pending бот мог ожидать бесконечно на выборе цели либо при нескольких задачах начала хода.

Добавлено узкое поддержанное окно для текущего владельца pending_whip. Цели берутся только из серверного pending и известных живых своих существ на поле; проверяются владелец и соседство/сам источник. Бот выбирает открытую цель, переживающую указанную рану, иначе использует штатную отмену. Чужой игрок не получает права выбора. У активной очереди начала хода поддержана только задача turn_start:whip, остальные неизвестные задачи автоматически не включены.

Эффект карты, урон, бонус движения и продолжения Engine не менялись. Рабочие партии/БД не изменялись. В последней сотне локальных battle-партий активный pending_whip при диагностическом чтении не найден; воспроизведение выполнено через нативные fixtures turn_task → pending_whip, а не через изменение пользовательского матча.

Проверки: test_bot_whip.php — 116; test_whip_cancel.php — успешно; test_bot_playtest_regressions.php — успешно; test_pending_wait_timer.php — успешно; test_stage_d.php — 203 проверки. Две последовательные способности, безопасная отмена смертельных/закрытых/недоступных целей, F5 roundtrip, чужой владелец, отсутствие повторного эффекта и read-only проекции проверены. Это адресная поддержка хлыста, не универсальная поддержка всех автоматических способностей ботом.

Файлы: PlayerObservation.php, LegalActions.php, CombatDecisionPlanner.php, tools/test_bot_whip.php. После обновления кода существующее сохранённое окно не требует ручного сброса; штатный bot tick сможет выбрать действие при следующем запросе.
