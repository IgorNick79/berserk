# View — исправления второго визуального ревью, 31 октября 2026

Текущие изменения локальны в codex/view-deck-ui; без commit/push/deploy и миграций.

## Исправления

1. Чипы пагинации возвращены, девять карт на странице. Убрана только видимая подпись номера/числа страниц. Страница, зона и фильтры сохраняются при AJAX; неполная последняя страница проверена.
2. Хинты сообщений и паузы используют существующий battle-icon-tooltip. Пауза получила отсутствовавшую разметку хинта. Выравнивание к правому краю кнопки удерживает текст в границах панели без обрезания.
3. Найдена причина потери всех хинтов подробностей: pregame-ui.js сохранял ссылку на заменяемую .pregame-layout. Для View обработчики теперь привязаны к стабильному .screen, переживающему AJAX. Показ проверен после первого и повторного выбора карты. Сам tooltip View использует существующий класс battle-stat-tooltip, а не отдельное оформление подготовки.
4. Выбранная карта получила существующие классы panel-card-heading / panel-card-cost / panel-card-heading-icons / panel-card-stats, непрозрачную поверхность текущей темы и разделитель. Текстура панели больше не просвечивает через блок подробностей.
5. Проверены четыре настоящих PNG стоимости. Уникальные файлы elite-unique.png и ordinary-unique.png имеют 64×64, обычные — 32×32. Уникальные выводятся размером 32px вместо 24px; небольшой светлый контур повышает читаемость встроенного тёмного декора. Новых картинок/нарисованных корон нет. Тест проверяет загрузку исходных unique PNG, naturalWidth и фактический размер видимых изображений.
6. Исправлена не только область запуска hover: для View paintZoom клонирует только img.view-art. Рамка, подложка, иконка стихии и полоса стоимости остаются на месте, в zoom-копию не входят. Для боя сохранено прежнее клонирование боевой миниатюры. Анимация остаётся общей: 250ms ease-out. Проверено сохранение одного zoom-узла при небольших движениях мыши внутри изображения.
7. Хинт стихии не содержит префикса «Стихия:» и располагается ниже значка. Используется существующая задержка 250ms; переход на значок прекращает увеличение.
8. .view-cost прилегает к самому низу и бокам карточки, просвет убран.

## Проверки и снимки

Набор View выполняет настоящие HTTP/DB и браузерные проверки в отдельном приложении с изолированной MariaDB, без production и без подмены этих проверок моками. Проверяются AJAX-перенос/возврат, потеря ответа и восстановление, конфликт версий, серверная пауза, чат, все четыре темы, реальные шрифты, четыре кристалла, подсказки после замены DOM, zoom только изображения, чипы, desktop и 360/390.

Артефакты в docs/evidence/view-deck:

- desktop-hover.png — увеличивается только иллюстрация.
- desktop-selected.png, desktop-image-close.png — непрозрачные подробности и крестик.
- view-details-hint.png — хинт подробностей после AJAX.
- view-element-hint.png — хинт под стихией без префикса.
- view-chat-hint.png, view-pause-hint.png — хинты нижних кнопок в пределах панели.
- browser-checks.json, http-checks.json — результаты прогона.

Снимки используют два предоставленных изображения с повторениями в тестовой колоде. Полный набор карт на production не загружался. Engine, PrepareProcessor, транспорт команд и серверные правила чата/паузы не изменялись. Незавершённая HTTP-регрессия боевого таймера из предыдущего этапа остаётся обязательной перед закрытием всей задачи.

Итог: 48 браузерных проверок, 19 HTTP/DB-проверок View и общий набор из 227 HTTP/DB-проверок (с браузерными наборами боя/комнаты/чата) прошли. JS-ошибок нет. PHP lint, JS/Python syntax, тест сайдборда и git diff --check прошли.
