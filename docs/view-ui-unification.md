# View — переиспользование боевого UI, 31 октября 2026

Этап выполнен поверх незакоммиченного редизайна View. Commit, push, deploy и миграции рабочей БД не выполнялись. Engine, PrepareProcessor, правила сайдборда, журналирование/CAS, серверный GameChat и доступность паузы по таймеру на этом этапе не изменялись.

## Аудит и выбранные компоненты

- Кнопки: семантическая палитра уже существует в battle-ui-skins.css: обычная зелёная, жёлтая, skip (синяя), cancel/red (красная). Материалы панели используют существующие account theme variables. View подключён к этим же селекторам; декларации кнопок не копировались в view-deck.css. Для жёлтого варианта добавлен семантический alias `.yellow` в существующую декларацию жёлтой кнопки. Переносы используют этот alias.
- Hover и название: напрямую подключены battle-mini-card.js, battle-mini-card.css, battle-mini-nameplate.css. Миниатюры View предоставляют существующие data-mini-card/data-mini-name. Собственная hover-анимация и верхняя плашка View удалены. Масштаб, задержки, позиционирование, z-index и reduced-motion принадлежат боевому модулю.
- Увеличенное изображение: напрямую используется card-image-popup.js и существующий CSS диалога/крестика. Минимальное расширение селектора корня позволяет подключить модуль к стабильному View-контейнеру. Изображение правой панели открывает этот диалог. Отдельного крестика в заголовке подробностей больше нет. View передаёт горизонтальный WebP, а не вертикальный оригинал.
- Пагинация: восстановлены прежние span-чипы из pregame-view.js и pregame.css. Логика страниц, фильтров, зон и AJAX не переписывалась; цифровые подписи на кнопках удалены, счётчик страницы сохранён.
- Кристаллы: используются elite.png, ordinary.png, elite-unique.png, ordinary-unique.png. Уникальность читается из фактического `single`, элитность — из `elite`, как в существующем PreGameCard. На первой странице тестовой колоды присутствуют все четыре комбинации, соответствие metadata → URL проверено.
- Чат: используется тот же game_chat.tpl, battle-chat.js и battle-chat.css. Из battle-ui.js выделены только операции открытия и размещения вторичной поверхности InfoPanel в panel-secondary-view.js; их вызывают и бой, и View. Приоритеты боя, выбор карты и боевые обработчики сохранены в battle-ui.js. Для View разрешены существующие theme/secondary-view селекторы. Живой узел чата сохраняется при обновлении HTML подготовки. Уведомления View используют уже существующий общий sound notifier с настройками аккаунта; ветка боевого таймера не изменена.
- Пауза: напрямую подключён BerserkMatchPause из battle-match-pause.js, включая его dialog/range, отсчёт, решения и основное действие «Вернулся / Готов». Независимый view-pause-dialog и его обработчики/оформление удалены. Добавлены только DOM-aliases и callback к уже согласованной функции отправки. Для подготовки изменён поясняющий текст, чтобы не обещать остановку отсутствующего таймера хода. Правила и разрешённые сервером команды сохранены. Общий текст паузы использует цвет существующей темы для читаемости.

## Минимальные адаптации

Общие селекторы оформления расширены на `.view-deck-page`; геометрия поля боя не применяется к View. Добавление класса info-panel потребовало нейтрализовать на View старые глобальные position:fixed/max-height/padding InfoPanel: сохранён прежний grid-контейнер подготовки. Это адаптация подключения общего компонента, а не перестройка панели или мобильный редизайн.

Сетка, 9 карт на странице, фоновые изображения, плашка стоимости/количества и существующая сводка сохранены. Новая сводка и новое пустое состояние не добавлены. Другие экраны подготовки не переводились на AJAX.

- templates/screen/view.tpl, battle.tpl, game_over.tpl, deal.tpl; www/index.php, www/lobby.php — ресурсы, зависимости и версии кеша. В PHP entry points этого этапа менялись только ссылки на UI-ресурсы.

## Проверки

Выполнены настоящие HTTP/DB-проверки на изолированной MariaDB/PHP, без production и без подмены DB/HTTP моками. Набор View проверяет 19 HTTP/DB-условий: принадлежность карты, идемпотентность, конфликт версий, конкурентные перенос/пауза, серверную блокировку переносов и подтверждения, переход подготовки, а также две DB-регрессии драфта.

32 браузерные проверки прошли без JavaScript-ошибок. Браузерный набор проверяет общий hover, увеличенное изображение/закрытие, четыре кристалла, чипы и неполную страницу, быстрый выбор, AJAX-перенос/возврат, потерю ответа с перезагрузкой, общий чат, паузу двух игроков, четыре темы и мобильную геометрию. Параметры всех четырёх цветовых вариантов кнопок (фон, рамка, радиус, высота, тень, шрифт) сравнены между настоящими страницами View и боя во всех четырёх темах.

Повторный существующий набор единого меню/мастера/комнаты/боевого и комнатного чата прошёл: 227 HTTP/DB-проверок, включая успешные браузерные наборы. PHP lint, JavaScript/Python syntax и git diff --check прошли.
