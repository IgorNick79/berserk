# Deal: AJAX, штраф и нижняя панель

Исправлены замечания визуального ревью:

- Выбранная миниатюра сохраняет outline, её border становится прозрачным, включая состояние deal-in-squad.
- «Вернуть» использует существующий боевой вариант cancel (красный); «В отряд» сохраняет стандартный зелёный.
- Штраф расположен у правого края строки ресурсов: «Штраф», настоящая иконка золота, положительная цифра величины штрафа. Вся конструкция является одной зоной общей подсказки с объяснением «Штраф за стихии: −N золото». Отображается только реальный положительный штраф ResourceCalculator.
- В нижнем блоке иконка пересдачи стоит перед «Выбрано».

## AJAX

Раньше game-transport.js перехватывал ссылки Deal и отправлял обычную форму. Для четырёх действий Deal (pick_card, unpick_card, reshuffle, confirm_deal) он теперь передаёт уже подтверждённое действие существующему клиенту view-deck.js. Прежние диалоги подтверждения сохраняются. Клиент использует тот же журнал команд, expected_version, sessionStorage и command_status для восстановления результата. Отдельного endpoint или второго исполнителя нет.

На сервере список доступа ограничен стадией и четырьмя командами Deal; проверка применяется до исполнения и повторно под executeLockedCommand. Функция preparationAjaxAllowed также сохраняет существующие правила View и MatchPause. Маршрутизация Engine, PrepareProcessor, правила набора и пересдачи не изменены. Во время requested/active паузы запрещённые действия отклоняются сервером; клиент дополнительно предотвращает их отправку. Остальные контекстные команды подготовки на AJAX не переводились.

## Реальные проверки

Изолированная временная БД, HTTP-серверы и Яндекс Браузер headless. Тестовые данные — готовая стадия Deal с действительными ресурсами, двумя стихиями и оставшимися картами в колоде; реальные SQL-каталоги, без моков серверного исполнения.

20 HTTP/DB-проверок: выбор, повтор команды без повторного выбора, конфликт версии, возврат, запрос/отмена паузы, блокировка всех четырёх действий паузой, пересдача, повтор пересдачи без второго списания золота, подтверждение обоими игроками и переход Deal → place.

8 браузерных проверок: прозрачная граница выбранной карты, выбор без навигации, красный вариант возврата, порядок пересдачи/счётчика, правое положение штрафа с настоящей иконкой и общая подсказка, возврат без навигации после реального выполнения запроса и потери HTTP-ответа. Проверена обработка потерянного ответа через восстановление, а не повторное выполнение действия. Ошибок JavaScript нет.

Пройдены PHP lint, синтаксис JavaScript, test_view_sideboard.php, test_preparation_engine_boundary.php и git diff --check. Скриншоты: docs/evidence/deal/selected.png и penalty.png. Прежние ограничения боевого таймера (отдельный сбой test_turn_timer_client.js и незавершённая полная HTTP-регрессия) этой правкой не исправлялись и не закрывались. Production не проверялся.

Commit, push, deploy и миграции рабочей БД не выполнялись.

Повторная регрессия View после изменения общего клиента и серверного доступа: 64 браузерные и 19 HTTP/DB-проверок пройдены, включая DB-регрессии драфта.
