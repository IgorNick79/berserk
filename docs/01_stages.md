# Стадии матча

Партия проходит через стадии:

deck → view → turn → side → deal → place → battle → game_over

## 1. deck — выбор деки

**Цель:** игрок выбирает стартовую деку, которой будет играть.

**Кто действует:** оба игрока одновременно.

**Что видит клиент:** список доступных стартовых дек.

**Что присылает клиент:** какую деку выбрал.

**Переход:** оба выбрали → `view`.

## 2. view — просмотр деки

**Цель:** подтвердить, что игрок знает состав выбранной деки.

**Кто действует:** оба игрока одновременно.

**Что видит клиент:** карты своей деки, разбивка по стихиям, количество элитных и обычных.

**Что присылает клиент:** подтверждение.

**Переход:** оба подтвердили → `turn`.

## 3. turn — бросок кубика

**Цель:** определить, кто выбирает сторону.

**Кто действует:** оба одновременно, автоматически.

**Что происходит:**

1. Сервер генерирует кубик для каждого (1–6).
2. Если значения равны — переброс обоих. Пока не станут разными.
3. Победитель переходит к выбору стороны.

**Что видит клиент:** свой кубик, кубик оппонента.

**Переход:** определён победитель → `side`.

## 4. side — выбор стороны

**Цель:** победитель кубика выбирает сторону.

**Кто действует:** победитель кубика. Проигравший ждёт.

**Что видит клиент (победитель):** выбор стороны (1 или 2).

**Что видит клиент (проигравший):** ожидание.

**Что присылает клиент:** выбранную сторону.

**Сторона 1** — ходит первой. **Сторона 2** — второй. Многие способности карт завязаны на сторону.

**Открытый вопрос:** кто выбирает сторону? Гипотеза — хост. Альтернатива — настройка или рандом (стадия пропускается).

**Переход:** сторона выбрана → `deal`.

## 5. deal — выбор карт в отряд

**Цель:** из раздачи собрать боевой отряд.

**Кто действует:** оба игрока одновременно.

**Что происходит:**

1. Каждому раздаётся 15 случайных карт из его деки.
2. Игрок выбирает карты в отряд (правила: лимит копий, уникальность, летуны, стоимость).
3. Можно пересдать (до 3 раз, с потерей ресурсов).
4. Не выбранные карты уходят вниз колоды.
5. Оба подтверждают отряд.

**Что видит клиент:** свою раздачу, ресурсы, статус оппонента.

**Что присылает клиент:** выбранные карты, пересдачу, подтверждение.

**Правила набора** — отдельный документ `deal_rules.md`, когда дойдём до стадии.

**Переход:** оба подтвердили → `place`.

## 6. place — расстановка

**Цель:** расставить отряд на своей половине поля.

**Кто действует:** оба игрока одновременно.

**Что происходит:**

1. Поле: 3 ряда каждому, по 5 клеток в ряду.
2. Игрок расставляет карты отряда на своей половине.
3. Оба подтверждают расстановку.

**Что видит клиент:** только своё поле. Поле оппонента в этой стадии не отображается.

**Что присылает клиент:** позиции карт, подтверждение.

**Переход:** оба подтвердили → `battle`.

## 7. battle — бой

**Цель:** бой до победы одной из сторон.

**Кто действует:** по очереди. У кого ход — тот действует. Оппонент может отвечать инстантами.

**Что происходит:**

1. Ходы по очереди.
2. Внутри хода — фазы (начало, восстановление, накопление, основной этап, конец).
3. Атаки, способности, инстанты, броски кубиков.

**Что видит клиент:** своё поле, свою руку, свои ресурсы. У оппонента — только открытое.

**Что присылает клиент:** команды (`play_card`, `move`, `attack`, `end_phase`, `end_turn`, `activate_ability`).

**Внимание:** `battle` — это 99% игры. Здесь общая карта, детали — в отдельных документах (фазы, приоритет, кубики, инстанты, стек).

**Переход:** уничтожены все существа одной стороны или сдача оппонента → `game_over`.

## 8. game_over — завершение

**Цель:** показать результат.

**Что происходит:** победитель, статистика, возможность выйти.

**Переход:** партия завершена.
