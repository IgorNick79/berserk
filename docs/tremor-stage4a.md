# Скелетный червь: этап 4А

Реализована специализация существующего pending_incarnation через incarnation.tremor. Готовность обеспечивается штатным накоплением четырёх жетонов (incarnation.turns=4); дополнительной оплаты монетами нет. Карта с tremor_on_graveyard без incarnation.tremor сохраняет обычные правила инкарнации.

TurnProcessor::processIncarnation включает готового Червя независимо от свободного заднего ряда, если Tremor::incarnationCells находит свободную клетку с Дрожью. Проверка занятости и блокирующих маркеров остаётся обязательной. Обычные карты используют прежнее условие заднего ряда.

IncarnationChoice и CellMarkerPicker предлагают допустимые клетки. Запрос содержит incarnation_id конкретного экземпляра: повторная команда не может примениться к следующей карте очереди. Сервер повторно проверяет владельца, кладбище, готовность, занятость и маркер. При нескольких Дрожах выбирается лексикографически первый ID. Расходуется один маркер после штатного размещения, сброса карты, бафов и пересчёта брони. Другие маркеры сохраняются. Если следующие Черви потеряли последнюю допустимую клетку, они исключаются из текущего pending с сохранением готовности на кладбище.
