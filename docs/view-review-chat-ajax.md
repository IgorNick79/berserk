# View: карточки, сообщения и обновление без мигания

У `.screen-prepare-view` убраны border и box-shadow. Декоративный view-frame удалён из HTML и CSS; невыбранные карты получили границу #607b69, выбранные сохраняют outline. Единственный чип скрыт через visibility: hidden, размеры навигации сохранены.

Встроенная панель сообщений больше не наследует внешние отступы плавающего чата: заголовок с существующей тематической заливкой занимает всю ширину. На стабильном корневом контейнере отмечается открытие вторичной панели; CSS скрывает действия карты и статистику, включая вновь полученные AJAX-фрагменты. Явное правило [hidden] устраняет конфликт с display: flex. Закрытие чата возвращает содержимое.

Причина мерцания: стили располагались внутри заменяемой разметки; AJAX удалял загруженные link и добавлял новые. Изначальные стили теперь постоянно находятся в head, а входящие фрагменты не вставляют стили и внешние скрипты повторно. При выборе карты старое содержимое остаётся до получения нового вместо предварительного удаления. Транспорт команд, серверные правила и движок не изменены.

Проверки выполнены в реальном локальном Яндекс Браузере (headless, отдельный профиль) с отдельной временной БД и двумя тестовыми аккаунтами. Пройдены 60 UI-проверок, включая 1600/1366/390/360 px, и 19 HTTP/DB-проверок. При задержке настоящего HTTP-ответа проверены сохранение старой панели, непрерывное подключение исходных stylesheet-узлов и положение кнопки подтверждения на каждом отслеживаемом кадре requestAnimationFrame. Проверены сообщения с фактически выбранной картой, повторная AJAX-замена при открытом чате, отсутствие действий карты и статистики, их восстановление при закрытии, скрытие единственного чипа без изменения высоты. Ошибок JavaScript нет. Пройдены PHP lint, JavaScript syntax, test_view_sideboard.php, test_combat_panel_ui.php и git diff --check.

Скриншоты: docs/evidence/view-deck/desktop-1600.png, desktop-chat.png, view-390.png, view-360.png. Иллюстрации тестовых карт — две предоставленные картинки. Полный каталог production и production не проверялись. Полная HTTP-регрессия таймера остаётся отдельной незавершённой проверкой общей задачи (TURN_TIMER_TEST_URL не настроен). Firefox и Google Chrome в этом прогоне не запускались.
