# LuckTest в LobbyWizard: этап 1

## Аудит и реализация

Ранее `quick_game=false` оставлял игру на Roll; `true` запускал существующие подтверждения Roll, выбор стороны, автоматическую расстановку и подтверждение Place в Engine. Добавлен `start_stage`: `turn`, `place`, `battle`. Для Place та же последовательность останавливается сразу после выбора стороны. Дальнейшая расстановка и начало боя выполняются прежними командами. Нового рендерера или алгоритма подготовки нет. В комнате автоматический проход до Place использует тот же транзакционный журналируемый маршрут, что быстрый старт Battle.

Исторические данные без `start_stage` интерпретируются через прежний `quick_game`. По умолчанию новый мастер выбирает Battle. Debug-сценарий с обязательными картами по-прежнему разрешён только для Battle, формат JSON, проверки доступа и серверные ограничения сохранены.

Балансировка специальных карт уже существует: в обоих отрядах совпадает признак наличия специальных карт (летающие или имеющие shot/throw/discharge). Количество таких карт и их сила не уравниваются. Нового алгоритма золота/серебра не обнаружено. По отдельному разрешению пользователя добавлена независимая сохраняемая галочка `balance_metals`, включённая по умолчанию, без влияния на генерацию. Это прямо указано в пояснении.

В мастере добавлен раздел «Основные настройки» с тремя радиокнопками, две галочки собраны в «Балансировку», пояснения открываются отдельно от галочек. Настройки количества карт и средней стоимости не менялись. Debug преобразован из fieldset/legend в обычную тематическую секцию, поля затемнены. За пределами мастера SettingsScreen не менялся. Подключён предоставленный пользователем золотой SVG 16×16: gap 6 px, отражение по вертикали вместо CSS-шеврона из границ.

## Уточнение после визуального ревью

Галочки балансировки и Debug используют один стиль. Пояснения выведены постоянно под настройками вместо вопросительных хинтов. Название первой настройки — «Летающие существа, пингеры». Пример JSON использует утверждённый золотой SVG.

После отдельного уточнения пользователя balance_metals теперь работает: дополнительный ограниченный поиск замен сближает отдельно суммы золота и серебра отрядов. Он принимает замену только при уменьшении валютного расхождения и без увеличения суммарного отклонения от прежней целевой стоимости отрядов. Фиксированные Debug-карты и выбранная категория специальных карт сохраняются. При выключенной галочке выполняется прежний подбор по общей стоимости, базовый баланс не отключается. Равенство валют не гарантируется: это приблизительный подбор, в том числе при ограниченном каталоге или обязательных картах.

`tools/test_lucktest_metals.php`: 49 проверок на 24 фиксированных seed; расхождение уменьшилось в 22 случаях, в остальных не увеличилось; базовая целевая стоимость не ухудшилась. Эти проверки выполняются отдельно от DB/HTTP.

Уточнение направления баланса: первый отряд теперь полностью фиксируется до валютной балансировки. Дополнительные замены выполняются только во втором отряде, относительно золотой и серебряной сумм первого. Выбор категории специальных карт и первый отряд не зависят от включения валютной галочки при одинаковом исходном seed. 73 проверки валютного баланса пройдены, включая неизменность первого отряда.
