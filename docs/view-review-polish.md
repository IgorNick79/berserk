# View — правки визуального ревью, 31 октября 2026

Изменения поверх ветки codex/view-deck-ui; commit/push/deploy не выполнялись.

- Белые разделители заголовка, статистики и footer заменены границами текущей темы. Видимая полоса прокрутки колоды скрыта, сама прокрутка сохранена.
- Крестик закрытия подробностей находится поверх изображения и появляется при наведении или фокусе, как существующий panel-card-close боя. На touch виден постоянно. Окно увеличенного изображения продолжает использовать общий card-image-popup.
- Сохранены четыре настоящих кристалла: обычные и уникальные золото/серебро. В резервных данных экземпляров/колод сохранён single; данные каталога дополняют их вместо потери отсутствующих полей. Новых обозначений уникальности нет.
- Действие переноса скрывается в режиме сообщений, включая обновления HTML. При закрытии чата возвращается.
- Жёлтый семантический вариант теперь использует существующую белую надпись жёлтой кнопки; dark-text alias удалён. Текст переноса центрирован по обеим осям, размер 14px.
- Пагинация View удалена. Все карты выбранной зоны отображаются в той же сетке с прокруткой; фильтры, выбранная зона и AJAX сохранены. Пагинация других экранов не менялась.
- Боевой hover имеет opt-in ограничение View: увеличение запускается только на иллюстрации. Подложка, промежутки, полоса цены и значок стихии не увеличивают карту.
- На стихии подключён существующий data-mini-hint с задержкой 250 мс. Уход курсора отменяет ожидающий хинт. Отдельного tooltip-компонента нет.
- Найдена причина Arial: View имел CSS с именами шрифтов, но не подключал файл шрифтов боя. Те же Golos Text (400/500/600/700) и Philosopher (400/700) теперь подключаются общим локальным battle-fonts.css в View, бою и итоговом экране. Размер файлов с лицензиями — 483943 байта. Источники: существующий Google Fonts CSS API, OFL из google/fonts; лицензии приложены в assets/fonts. Новых шрифтов или начертаний не вводилось.

Проверка реального рендеринга через Chrome DevTools Protocol (не только computed CSS): надпись переноса — GolosText-Bold, переключатель колоды — GolosText-Regular/Bold, заголовок — Philosopher-Bold; Arial не используется. Результат: docs/evidence/view-deck/rendered-fonts.json. Arial остаётся лишь резервом в прежнем общем font stack, если пользователь явно блокирует все шрифты.

39 настоящих браузерных проверок прошли без JS-ошибок: общая карта/чат/пауза, переносы и восстановление после потери ответа, все четыре темы и кристалла, отсутствие пагинации, прокрутка полного списка, появление крестика, белый центрированный текст, хинт стихии, отсутствие zoom подложки, локальные и фактически отрисованные шрифты, mobile 360/390 и desktop. 19 HTTP/DB-проверок изолированного набора также прошли, включая две DB-регрессии драфта. PHP lint, JS syntax, тест сайдборда и git diff --check прошли.

Скриншоты: docs/evidence/view-deck/desktop-selected.png, desktop-image-close.png, desktop-hover.png, desktop-chat.png, view-360.png и view-390.png. Полный набор production-иллюстраций не загружался: локально по-прежнему только два примера пользователя с повторениями.

Engine, транспорт, серверные правила сайдборда, чата и паузы не менялись. Ранее отложенная HTTP-регрессия боевого таймера остаётся обязательной перед окончательным закрытием всей задачи.
