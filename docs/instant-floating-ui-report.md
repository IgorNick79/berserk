# Компактное управление инстантами

После визуальной корректировки: в свёрнутом состоянии над содержимым справа
снизу видна только молния `images/battle/instant.svg`. При раскрытии молния
исчезает, а обычный блок управления располагается внизу на ширину InfoPanel.
Это часть компоновки: содержимое прокручивается выше блока и не перекрывается
им. Закрытие возвращает молнию и всю высоту содержимому. Нижний ряд сохранён.

## Поведение

- Обычная доступность: иконка без анимации, панель закрыта; активному игроку
  доступны «Сыграть» и штатный список, пассивному — серверный резерв с ценой
  и остатком. Открытие панели не отправляет игровых команд.
- Заголовок у обеих сторон — «Инстант». Цена и остаток стоят рядом с ним,
  без отдельной строки. При одновременных серверных правах паса и отказа
  показывается только обычный «Пас»: он сохраняет передачу приоритета.
  Серверный отказ, который сразу закрывает пустое предоставленное окно,
  не подменяет пас и выводится только при отсутствии права паса.
- Зарегистрированный резерв: зелёный индикатор, штатная отмена в панели.
- Обязательное решение: золотой индикатор и автоматическое раскрытие по
  существующему серверному праву паса/отказа. Можно свернуть панель для доступа
  к содержимому; акцентированная иконка остаётся доступна в один клик.
- Нет прав/способностей/резерва: слой не выводится. Пауза и завершение матча
  сохраняют действующую доступность. Локальный псевдопас вне стека не выводится.
- AJAX сохраняет добровольное раскрытие, раскрытие списка и его прокрутку
  для того же контекста. Новая фаза/стек/права сбрасывают устаревший список.
  Одинаковые snapshot не раскрывают закрытый блок повторно. F5 восстанавливает
  обязательное раскрытие из серверной разметки.
- Pending-выборы и результаты сохраняют свой приоритет. Блок расположен вне
  overflow содержимого, список имеет собственную прокрутку. При переполнении
  содержимого добавляется только прокручиваемый хвост, позволяющий добраться
  до нижней правой кнопки под иконкой; высоту scrollport он не уменьшает.

## Ограничения и известные проблемы

- `test_battle_stage1a_ajax_layout.php` ожидает debug-target у бургер-меню.
  Та же ошибка воспроизведена в отдельном worktree исходного `d9c83a6`.
  Связи с этим изменением нет; меню не менялось.
- Старое предупреждение `player_settings` в `www/index.php:340` остаётся
  в изолированных HTTP-логах; соответствующий код не менялся.
- На 800 px прежний нижний ряд переносится на две строки, а поле требует
  существующей горизонтальной навигации. Эта компоновка сохранена.
- Телефонная адаптация не разрабатывалась. Исторические несовпадения старых
  тестов заголовков UI из отчёта Stage E остаются отдельной задачей.

Игровой движок, `InstantControl::project()`, стек, резервирование, стоимость,
доступность, ACK и continuation не изменялись. Миграции не применялись.
