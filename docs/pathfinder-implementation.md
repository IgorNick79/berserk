# Следопыт

Реализована процедура в статусе place. PrepareProcessor::confirmPlace после двух первоначальных подтверждений вызывает PathfinderProcessor::begin. Если есть право Следопыта, переход в battle откладывается. Engine::confirmPreparePlace по-прежнему является единственной точкой вызова startBattle по событию stage_changed:battle. Обработчик pathfinder_choice не начинает бой самостоятельно, а повторно использует штатное подтверждение.

PathfinderProcessor хранит battle.pathfinder: queue, index, owner, stage, revealed_to. Очередь построена по getFirstPlayerKey() (сторона 1 предыгрового определения), затем его противник. От каждого владельца включается только один элемент независимо от числа карт с pathfinder_rearrange. Вскрывается выбранный экземпляр Следопыта. Переходы: первоначальный place → choice → rearranging/отказ → следующий choice → complete → обычный battle. Повторный запрос choice проверяет стадию и индекс. Завершённая процедура не открывается повторно.

Повторное размещение использует существующие place_card/unplace_card, проверки владельца, половины поля, уровней допустимых клеток и занятости. Для повторного place меняются только зона/координаты существующих экземпляров: эффекты выхода с поля и обычного движения не вызываются. Подтверждения первоначальной расстановки остальных игроков сохраняются. Новые карты, броски, инициализация и таймер до окончательного перехода не создаются.

PlaceScreen показывает актуальный первый ряд соперника только зрителю, уже получившему право процедуры. Отдельно видны вскрытые Следопыты, включая перемещённого из первого ряда. Остальные карты на дополнительных рядах фильтруются до рендера, их имя/ID/изображение не добавляются в HTML поля. Перестановка не меняет revealed других карт; при начале боя выполняется обычная видимость, с сохранением индивидуального pathfinder_revealed для самого Следопыта. Ожидающий игрок видит заданный текст. Редактор и ссылки остаются существующими; pregame-place.js получил новую команду в список POST-действий. История допускает pathfinder_choice как предбоевую команду, которая может окончательно запустить initial боя.
