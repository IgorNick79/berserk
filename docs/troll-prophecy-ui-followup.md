# Имена и видимость результата пророчества Тролля

Окно «Двухголового тролля» теперь подставляет отображаемое имя цели вместо
`ukid`. Цель явно указана и для двух рядовых карт: «Зомби: отравление 2».
Старые сохранённые заголовки также поддержаны: имя берётся из кода в тексте
либо из цели соответствующего текущего удара.

Результат удара/яда от пророчества показывается обеим сторонам поверх ранее
осмотренной карты. Закрыть окно, как и раньше, может только владелец пророчества.
Это одно общее ожидание, а не отдельный ACK второго игрока; после закрытия
владельцем окно исчезает у обоих. Правила урона, отравления и движения колоды
не менялись; в pending добавлена только ссылка на карту для заголовка.

Проверки: 62 native/UI (оба владельца, обе стороны просмотра, урон и яд,
права закрытия, F5, старые сохранения); 76 браузерных (4 сценария по 19,
Edge 1600/800, осмотр → результат, snapshot и F5). Прошли регрессии движения
колоды пророчества (17 новых и 93 effective-feature), результат инстанта (13),
combat UI и PHP lint. Рабочая БД не изменялась.
