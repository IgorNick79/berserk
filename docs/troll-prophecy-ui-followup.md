# Имена и видимость результата пророчества Тролля

Окно «Двухголового тролля» теперь подставляет отображаемое имя цели вместо
`ukid`. Цель явно указана и для двух рядовых карт: «Зомби: отравление 2».
Старые сохранённые заголовки также поддержаны: имя берётся из кода в тексте
либо из цели соответствующего текущего удара.

Само пророчество закрывает его владелец. После подтверждения обычных результатов
сражения появляется отдельный итог эффекта для обоих игроков. Он использует
существующие `strike.results`, `confirm_strike`, `wait_id` и информационный таймер.
Частичный ACK оставляет результат второму игроку; устаревшие и повторные ACK
его не пропускают. Затем продолжаются прежние боевые продолжения и поздние окна.
Порядок применения урона/яда прежний: результат сохраняется при срабатывании
способности, а позже только показывается. Для яда отображается фактический маркер,
включая отсутствие эффекта или уже существующее более сильное отравление.

«Карта закрыта» использует один шаблон для полной страницы и AJAX. Старые
фрагменты с `p.wait` нормализуются в тот же `panel-card-status`. Общий стиль
перенесён из skins в базовый CSS, чтобы оформление не зависело от версии темы.

Для уже открытого старого пророчества с отравлением при закрытии сохраняется
результат существующего маркера; повторного применения яда нет.

Проверки: 142 native/UI (оба владельца, оба зрителя, урон/яд, порядок окон,
два ACK, F5, старые сохранения, stale/duplicate ACK, отсутствие повторных эффектов,
совпадение серверного HTML статуса); 152 браузерных (8 сценариев по 19,
Edge 1600/800, после боя → информация, осмотр, snapshot и F5).
Статус закрытой карты: ещё 7 браузерных проверок, включая замену старого AJAX
HTML и точное сравнение размеров/стилей с F5. Прошли Stage 4, C1/C2/D,
информационные ожидания, таймер/timeout, бот, порядок колоды пророчества,
результаты инстантов, combat UI, PHP lint и JS syntax.
Рабочая БД не изменялась.
