AbyssMovement — адресное сериализуемое продолжение, продвигаемое после успешной команды Engine. Оно сохраняет исходный результат/ожидания действия, исполняет список целей по ID и возвращает исходный контекст после завершения. Индекс сдвигается до applyDamage; обязательные последствия заканчиваются до следующей цели. Для impact переиспользован DamageResolver, включая броню, shield_light, CardHealing, on_death/on_any_death и вложенные выборы. DeathEffectContext предоставляет доступ к текущей адресной очереди заданий существующего обработчика смерти: код Червя не копировался, обе карты не вызывают друг друга. Обычные смерти вне адресного контекста используют прежнюю ветку. AbyssMovementChoice проверяет operation_id/choice_id через DamageResolver. BattleWaitResolver определяет владельца смерти. Проверка устранения отложена до завершения очереди ранений, сдача остаётся немедленной.
