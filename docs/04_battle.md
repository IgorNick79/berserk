# Стадия Battle

Бой — основная стадия игры. Здесь происходят все действия:
движение, атаки, способности, розыгрыш карт.

## Общая схема

Игроки ходят по очереди. В свой ход игрок действует картами
на поле. Когда игрок завершает ход — приоритет переходит
к оппоненту. И так до победы.

## Ход игрока

Внутри хода — фазы. Пока делаем минимальный набор,
потом расширим.

| Фаза | Что происходит |
|---|---|
| Начало хода | Открываются закрытые карты, обновляется `move` |
| Основной этап | Движение, удары, способности |
| Конец хода | Триггеры «в конце хода» |

**Важно:** в первой версии боя фазы «Начало» и «Конец»
делаем минимально — только восстановление карт и `move`.

## Карта на поле

У каждой карты на поле есть состояния:

| Состояние | Что значит |
|---|---|
| `move` | Сколько шагов осталось в этот ход |
| `closed` | Карта уже действовала (атака/способность) |
| `markers` | Жетоны (яд, огонь, оглушение) |

### Закрытость

Когда карта атакует или использует способность — она
становится **закрытой** (`closed = true`). Закрытая карта:

- Не может двигаться.
- Не может атаковать.
- Не может использовать способности.
- Не может отвечать на удары (защитник не бросает кубик).

Закрытая карта открывается в начале хода своего владельца.

На клиенте закрытая карта отображается через opacity или
цвет — не через поворот.

### Движение

Движение тратит `move`. Одна клетка — один пункт `move`.
Движение не закрывает карту.

`move` обновляется в начале хода владельца до значения
из справочника карты.

### Удар (strike)

Простой удар — атака по соседнему существу. Требует,
чтобы карта была **открыта**. После удара карта закрывается.

Удар запускает бросок кубиков: оба игрока (атакующий и
защитник) бросают кубик. Результат определяет исход
(слабый/средний/сильный удар или промах).

#### Защитник

Оппонент, увидев атаку, может выставить защитника.

**Требования к защитнику:**
- Должен быть **открытым** (не `closed`).
- Должен стоять **рядом с атакующим** И **рядом с атакованным**.
- Может быть летающей картой.
- Один защитник на удар.

**Если защитник выставлен:**
- Бросок кубиков между атакующим и защитником.
- Атакованный **не участвует**.
- Урон получает защитник.
- Защитник закрывается после сражения.

**Если защитник не выставлен:**
- Бросок между атакующим и атакованным (если атакованный открыт).
- Если атакованный закрыт — бросок только атакующего.

### Способности

У карты может быть несколько способностей (`actions` в `prop`).
Игрок выбирает, какую использовать. Способность закрывает карту.

Способности бывают:

- **Активируемые** — по клику, как удар. Тратят фишки (`coins`),
  если указано.
- **Триггерные** — срабатывают сами в определённый момент
  (в начале хода, при атаке и т.д.).

Триггерные способности — отдельный слой, делаем позже.

## Модификаторы

Модификации карт привязаны к **инстансу**, а не к справочнику.
Два одинаковых Кшара — два разных инстанса. Изменение одного
не влияет на другого.

Модификатор — запись в `CardInstance.modifiers`:

- `stat` — что меняем (`move`, `strike_medium`, `uchr_value`, ...).
- `value` — на сколько. Может быть отрицательным.
- `expire` — когда снимать (`end_of_turn`, `permanent`, ...).

Модификаторы не перезаписывают `prop`. Они читаются поверх
справочных значений в момент применения эффекта.

## Кубики

Броски генерирует **сервер** в момент объявления действия.
Оба кубика известны сразу, оба клиента видят результат.

**Правило топора:** нельзя атаковать, если у атакующего
нет ни одного типа удара (все три `strike_*` = 0).

### Таблица ударов

Результат определяется по разнице кубиков:

| Разница | Результат |
|---|---|
| ±0 и ≤4 | слабый удар атакующего |
| +1 | слабый удар атакующего |
| +2 | средний удар атакующего, слабый защитника |
| +3 | средний удар атакующего |
| +4 | сильный удар атакующего, слабый защитника |
| ≥+5 | сильный удар атакующего |
| −3 | слабый удар защитника |
| −4 | средний удар защитника, слабый атакующего |
| ≤−5 | средний удар защитника |
| 0 и ≥5 | слабый удар защитника |

*(Таблица — из старого кода `strike_table`. Если правила
изменились — правим.)*

## Победа

Бой заканчивается, когда:

- У одной стороны уничтожены все **существа** (не все карты).
- Один из игроков **сдался** (кнопка сдачи, ещё не сделана).

## Сдача

Отдельная команда `resign`. Игрок в любой момент своего
хода может сдаться. Оппонент побеждает. Кнопку добавим.

## Протокол команд

| Команда | Что делает |
|---|---|
| `move` | Двинуть карту на соседнюю клетку |
| `strike` | Атаковать карту (запускает кубики) |
| `ability` | Использовать способность карты |
| `end_turn` | Завершить ход |
| `resign` | Сдаться |

## Что видит клиент

Своё поле полностью, включая закрытые карты. Поле
оппонента — открытые карты как есть, закрытые — рубашкой.

На стадии `battle` (в отличие от `place`) поле оппонента
показывается — иначе не понять, куда атаковать.

## Открытые вопросы

- Полная последовательность фаз внутри хода (пока упрощаем).
- Что именно делают фазы «Начало» и «Конец» помимо
  восстановления.
- Момент активации триггерных способностей.
- Инстанты и стек — слой 4 в общем плане, здесь не описываем.
- Ходьба через занятые клетки — можно или нет.
- Диагональное движение — по умолчанию нет (только прямо),
  но у некоторых карт есть способность.
- Что происходит при атаке по закрытой карте.

## Что делаем в слое 1

Минимум для рабочего боя:

- Ход по очереди (`end_turn`).
- Движение на соседнюю клетку.
- Простой удар по соседнему существу.
- Бросок кубиков с таблицей удара.
- Открытие закрытых карт в начале хода.

Три Кочевника у каждого. Этого достаточно для первого
играбельного боя.

Способности, триггеры, инстанты, стек, победа, сдача —
следующие слои.
