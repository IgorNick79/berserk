# Сшиватель плоти — быстрый сценарий LuckTest

Включить LuckTest → Быстрая игра, установить **3 карты на сторону**, вставить JSON из `docs/flesh-stitcher.lucktest.json` в поле обязательных карт. Поле доступно аккаунтам с разрешённым Debug. Стихии подтверждены чтением каталога, БД не изменялась.

Хост:
- s1_148 — Сшиватель плоти, 1/8 HP, клетка 2_3.
- s1_151 — Зомби, 1/11 HP, клетка 1_2.
- s1_141 — Моровой всадник, 1/7 HP, клетка 1_4.

Все три существа тёмные. В координатах хоста это Сшиватель [II:3], Зомби [III:2], Моровой всадник [III:4]. Соседние клетки вокруг Сшивателя свободны для последующего возрождения. Противник получает два Зомби и Морового всадника с обычным полным HP.

Сразу доступны раненые цели для лечения и получения жетонов. Сам Сшиватель тоже ранен и может лечить себя. Для возрождения нужно накопить 3 жетона и дать противнику убить двух союзников: этот сценарий задаёт начальную расстановку, а не заполненное кладбище. У Морового всадника остаётся штатная инкарнация. Если первым ходит противник, передать ход хосту. Готовый prop Сшивателя из `docs/flesh-stitcher.prop.json` должен быть применён вручную отдельно.

## Поле hp в JSON

В `cards` поддерживается необязательное `hp`: положительное целое число, не превышающее hpMax карты. В `deck` поле запрещено. Максимальное здоровье и справочник карт не меняются. Без hp действуют прежние правила полного здоровья.

Начальное здоровье применяется к связанному экземпляру после успешной проверки расстановки Quick Game и до штатного начала боя и его первого снимка истории. Стартовые способности и последующее лечение работают как обычно. Повторная отправка confirm_settings после старта не применяет HP заново. Новых команд изменения HP во время боя нет.

Изменены `LuckTestScenario.php` (разбор/валидация/начальное HP), `Engine.php` (один вызов в границе Quick Game), `LuckTestDebugFields.php` (справка). Созданы JSON, этот документ и `tools/test_lucktest_scenario_hp.php`.

Проверки выполнены на отдельной копии без рабочей auth-конфигурации и без настоящей БД: базовые LuckTest 186, manual 1014, Debug 218 и новые сценарные HP 153 проверки — успешно. Новые проверки включают JSON целиком, все карты хоста на 1 HP, здорового противника, сериализацию, отсутствие повторного применения, запрет нуля/отрицательных/нецелых/строковых HP, превышения hpMax и HP в резерве. Изолированный каталог использует тестовые характеристики, реальные стихии/здоровье отдельно сверены READ ONLY запросом.
