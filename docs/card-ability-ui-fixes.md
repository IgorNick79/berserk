# Исправления интерфейса способностей карт

База: d237139, ветка codex/card-ability-ui.

## Бал-Бугур

Реализация фонаря оставалась в feature/bulbagur (9924c5a) и отсутствовала в main. Перенесены обработчик выбора направления, регистрация pending, создание и отображение света, расчёт дополнительных ран и тесты. Изменения адаптированы к текущему DamageResolver с журналом и BattleWaitResolver с таймерами. Выбор принадлежит владельцу карты в начале хода противника. Закрытая карта сохраняет пассивную способность; прочие отключённые эффекты не включаются.

Файл docs/cards/s1_119.prop.json перенесён как эталон конфигурации. БД и существующие GameState не изменялись: наличие нужного opponent_turn_start в конкретном каталоге/сохранении проверяется отдельно при публикации. Для уже созданного матча свойства берутся из его сохранённого состояния.

## Шакси

Сохранённый результат показан визуальным кубиком, как у Тергалы, без повторного броска. Цели используют общий цветной формат координат с римскими рядами и ориентацией смотрящего. Названия карт экранируются.

## Болотник

Режим прыжка показывает только фиолетовые цели с opacity 0.6, контуром и усилением при наведении. Зелёные ходы скрыты. На пересечении целей ссылка выполняет jump, а не move. Обычный режим сохраняет ходьбу. Правила допустимых перемещений не изменены.

## Проверка

- 17 тестовых наборов прошли; результаты: evidence/card-ability-ui/regressions.json. В том числе 976 проверок фонаря и 96 проверок интерфейса способностей.
- Тест журнала запускался в одноразовой копии src/tools с отдельным storage, согласно его защитному условию.
- PHP 8.1.9: lint 13 изменённых/добавленных PHP-файлов без ошибок.
- Headless Edge / Playwright: семь HTML-сценариев, снимки и browser.json в evidence/card-ability-ui. Проверены кубики обеих сторон, отсутствие зелёных ходов при прыжке, три маркера света. Это проверка сформированных экранов, а не живой матч с production БД.
- Diff review: ActionResolver меняет только отображение реально нанесённых ран; Engine, Grid и Recorder не изменены. git diff --check проходит.

Production SQL, push, merge в main и deploy не выполнялись. Изменения feature/bulbagur перенесены выборочно, её история и указатель сохранены.
