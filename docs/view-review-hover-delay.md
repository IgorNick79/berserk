# View: задержка увеличения и отмена кликом

Увеличение иллюстрации View начинается через 300 мс. Нажатие основной кнопки мыши отменяет таймер и уже открытое увеличение; click также отменяет hover, включая программную/клавиатурную активацию ссылки. Подавление сохраняется по UKID после замены DOM: под неподвижным курсором выбранная карта повторно не увеличивается. После ухода курсора и повторного наведения увеличение работает штатно. На значке стихии таймер увеличения отменяется; существующая задержка хинта 250 мс сохранена. Боевая задержка остаётся 200 мс, игровые команды не изменены.

Пройдены 64 UI-проверки в локальном Яндекс Браузере headless и 19 проверок в отдельной HTTP/DB-среде. Новые проверки покрывают быстрый клик с задержанным реальным ответом и заменой DOM, отсутствие увеличения до задержки, переход на стихию до запуска zoom и возврат на изображение. Пройдены JavaScript syntax и git diff --check. Production, Google Chrome и Firefox отдельно не проверялись. Ранее незавершённая полная HTTP-регрессия таймера остаётся отдельной проверкой общей задачи.

Commit, push, deploy и миграции рабочей БД не выполнялись.
