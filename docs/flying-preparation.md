# Подготовка к атаке летающих

Реализация: обычный strike открывает стандартный PanelSpec через ChoiceRegistry, если наземному источнику требуется подготовка. Подтверждение повторно проверяет условия и закрывает карту без создания strike. Операция привязана к случайному operation_id и владельцу; повторное подтверждение отклоняется.

Семантика can_attack_flying: CardStats поддерживает true и условное разрешение; docs/05_cards.md приводит Скелоса. Ограничение расстояния не задано. docs/stage-3.4b-autonomous-flying-units.md уже фиксирует соседство с null-координатами как серверный дефект. Для наземного удара по летуну StrikeResolver проверяет общий список BattleHelper и пропускает только пространственную проверку. Существующая способность не требует подготовки. Наземные цели используют прежние проверки.

flags.flying_preparation хранится в сериализуемой CardInstance: waiting после подтверждения, ready после окончания хода противника. В конце следующего собственного хода удаляется, включая использованную подготовку. Уход с поля через EffectiveFeatures::leftBattlefield очищает флаг. Подготовка не хранит target_id. Любой живой наземный противник блокирует подготовку и применение, даже если он далеко. Появление наземного после инкарнации не отменяет флаг досрочно, но блокирует его применение. В InfoPanel остаётся пояснение условного разрешения.
