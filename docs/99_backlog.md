# Задачник

## Инфраструктура

- **Бустер** — механизм создания бустера из карт.
  Открытие пакета, анимация, выбор карт.
  Связано с режимом «силед»/«драфт».

- **Логи партии** (`game_events`) — структурированные события.
  Реплеи, отладка, статистика.

- **Автообновление UI** — polling или WebSocket.
  Без F5, чтобы видеть ход оппонента.

- **AJAX** — вместо перезагрузки страницы.
  Клик по карте — обновление только её части.

## Механики — доп. жизни

- **grant_hp_bonus** — раздача дополнительных жизней по действию.
  - Фильтры цели: self / near / own / ally.
  - Увеличивает `hpMax` (и `hp`) цели на N.
  - Источник: Ведьма слуа, будущие карты.
  - Начинает карту с `hp_max_override` для базового максимума.

- **reduce_hp_max** — снятие доп. жизней у себя.
  - Игрок выбирает X, `hpMax -= X`, `hp` подрезается по новому максимуму.
  - Требует диалог выбора количества (общий с Мастером топора).
  - Источник: Ведьма слуа.

- **extra_hp_count** — счётчик карт с доп. жизнями.
  - Считает своих карт, у которых `hp > baseHp` (из справочника).
  - Для динамического урона.
  - Источник: Керсамская знать.

- **Универсальный диалог выбора количества** — общий UI-механизм.
  - Мастер топора — сколько монет потратить.
  - Ведьма слуа — сколько доп. жизней снять.
  - Керсамская знать — выбор цели (уже есть) + счётчик.
