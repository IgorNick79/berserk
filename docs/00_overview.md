# Berserk Online

Онлайн-версия карточной игры «Берсерк». Играют двое: один против другого.

## Что делаем

- Веб-версия (PHP + JS).
- В перспективе — Android-приложение.
- Игровая логика полностью на сервере.
- Клиент — тонкий, рисует то, что пришло с сервера.

## Стек

| Слой | Технология |
|---|---|
| Сервер | PHP 8.4 |
| БД | MySQL |
| Клиент | JavaScript |
| Хостинг | Masterhost (Apache) |

## Принципы

- **Сервер авторитарный.** Клиент шлёт намерения, сервер решает.
- **Скрытая информация — через проекцию.** Игрок видит только своё.
- **Состояние партии — в JSON.** В БД живут только справочники и партии.
- **Логика отделена от рендера.** Ядро не знает про HTML.
- **Итерации маленькие.** Сначала 3 Кочевника, потом карты по одной.
